## 1. プロジェクト概要
- **目的**: FANZAアフィリエイトを通じて収益化を図る、ニューハーフジャンルに特化したアダルトアフィリエイトサイトの構築・運用。
- **目標**: 3ヶ月以内に月額3万円の安定収益化。
- **主な収益源**: FANZA単品動画購入報酬（6〜10%）、FANZA有料会員登録報酬（2,000〜5,000円/件）。
- **ターゲットユーザー**: ニューハーフAVに興味がある層（購買意欲が高く、リピート性が強いコアなファン層）。

---

## 2. 技術スタック（完全無料・Antigravity構築前提）

| コンポーネント | 採用技術 | 理由 |
|--------------|----------|------|
| **フロントエンド** | Next.js (App Router) + Tailwind CSS | 高速なSSG/ISR生成、SEOに強い、コンポーネント化しやすいため。 |
| **ホスティング** | Cloudflare Pages | 無料で制限が緩く、アダルトコンテンツ（合法/規約範囲内）のホスティングに利用される実績があるため（※VercelのToS回避）。 |
| **データベース** | ローカルJSONファイル集 or Supabase | 初期はMarkdown/JSONファイルベースの静的運用で十分。拡張時にSupabase（PostgreSQL）へ移行。 |
| **データソース** | FANZA Affiliate API | 作品情報（タイトル、パッケージ画像、女優名、ジャンル、詳細）を自動取得するため。 |
| **記事生成 AI** | ローカルLLM (Ollama + Llama3.1/Mistral等) | APIの「アダルト生成制限方針」を回避し、自動・大量にレビューテキストを生成するため。 |

## 3. サイト構造・ページ構成

Googleのクローラーが巡回しやすい、フラットで論理的な構造（パンくずリスト必須）とする。

### 3.1 ページツリー
```text
/ (トップページ: 新着・おすすめ・人気ランキング)
├── /verify/ (★年齢確認クッションページ: 必須)
├── /actress/ (女優一覧・個別ページ)
│   └── /actress/[id]/ (女優プロフィール・出演作品一覧)
├── /genre/ (ジャンル一覧 - 「フェラ」「M男」など掛け合わせ)
│   └── /genre/[id]/ (ジャンル別作品一覧)
├── /review/ (作品レビュー記事一覧)
│   └── /review/[id]/ (個別作品レビュー記事 - ★ここがメインの集客口)
├── /column/ (解説・まとめ記事 - E-E-A-T向上用)
│   └── /column/[id]/ (例: 「2025年最新ニューハーフおすすめTOP10」)
└── /legal/ (プライバシーポリシー、免責事項、運営者情報など)
```

### 3.2 必須機能
- **年齢確認機能**: 初回訪問時に「18歳以上ですか？」のモーダルまたはクッションページを表示（法律・規約上のリスク軽減）。
- **アフィリエイト明記**: ヘッダーまたは記事上部に「本サイトはプロモーションが含まれています」の記載（景品表示法・ステマ規制対応）。
- **OGP自動生成**: Next.jsの `metadata` を活用したSNSシェア時の画像・説明文の自動設定。

## 4. コンテンツ戦略と記事テンプレート

SEOとコンバージョン（CV）の両立を目指す。文字数は1,500〜3,000文字目安。

### 4.1 記事の型（テンプレート）設計
記事構成は行動心理学（AISAS等）に基づき、以下の順番で構成する。

1. **アイキャッチ＆導入 (Catch)**: ユーザーの検索意図（「エロい」「おすすめ」等）を満たす結論を先に書く。**ファーストビューに1つ目のアフィリンク（ボタン）を配置**。
2. **作品概要・スペック**: FANZA APIから取得した基本情報（女優、メーカー、時間、ジャンル）を表形式で簡潔に提示。
3. **見どころ解説 (Body - 画像連発)**:
   - 記事中盤に公式サンプル画像を3枚前後連続して配置（視覚的刺激）。
   - 画像の下には**必ず人間味のある（LLMが生成した）独自の感情的なレビュー文**を添える。
4. **おすすめする人・しない人**: ターゲットを明確にし、共感を生む（E-E-A-Tの「経験」を演出）。
5. **クロージング＆CTA (Action)**: 「今すぐFANZAで見る（無料サンプルあり）」といった行動喚起ボタンを大きく配置。

### 4.2 リンク・CTA（行動喚起）の最適化
- **スマホ特化デザイン**: ユーザーの7〜8割がスマホ接続と想定。ボタンは親指で押しやすい「幅広・大きめ」にする。
- **マイクロコピー**: ボタンの直上に「お得な情報」や「サンプル動画あり」など、クリックのハードルを下げる一言を添える。
- **追従ボタン (Sticky CTA)**: スマホ閲覧時、画面下部に常にFANZAへの誘導ボタンを固定表示させる。

## 5. UI/UX デザインガイドライン (2025年トレンド対応)

- **ダークモードベース**: アダルトサイトの基本であり、深夜帯の閲覧（目に優しい）を想定。黒背景にアクセントカラー（ピンクやゴールド等）を採用。
- **高速表示 (Core Web Vitals対応)**: Next.jsの `<Image>` コンポーネントを活用した画像の遅延読み込み（Lazy loading）とWebP最適化。
- **直感的なナビゲーション**: ハンバーガーメニューよりも、スマホ画面下部に固定された「タブバー（ホーム・検索・女優・ランキング）」を採用し、片手操作性を向上。
- **「人間に優しい」設計**: アダルト特有の過剰な点滅バナーやポップアップ（年齢確認以外）は排除し、クリーンで高級感のある「専門メディア」としてのブランディングを図る。

## 6. 自動化パイプライン (今後の実装タスク)

データ取得から公開までのフローを以下のように設計する。

1. **データフェッチ**: Node.jsスクリプトで定期的にFANZA APIを叩き、新着またはランキング上位のニューハーフ作品リスト（JSON）を取得。
2. **記事生成**: ローカルLLMにJSONデータ＋「あなたの口調プロンプト」を渡し、見出し・本文・メタディスクリプションをマークダウン形式で自動生成。
3. **ビルド＆デプロイ**: Gitリポジトリに変更（新しいMarkdown/JSONファイル）をPush。Cloudflare Pagesがそれを検知してNext.jsプロジェクトを静的ビルド（SSG）し、自動デプロイ。

---

> **🚨 注意事項 (DMMアフィリエイト運用ルール)**:
> - **利用可能な画像**: 「パッケージ画像」「サンプル画像(小)(大)」のみ。
> - **画像の加工制限**: 画像の「拡大・縮小」のみ許可。切り抜きやモザイク追加、文字入れ等の加工は**一切禁止**。
> - **テキストの引用禁止**: 公式サイトの「商品説明文」や「ユーザーレビュー」の引用・転載は**禁止**。オリジナルのレビュー文をAIに生成させること。
> - **不正な誘導の禁止**: ユーザーが意図しない挙動（騙しリンクやリダイレクト）でのFANZAへの遷移は禁止。
> - 無修正画像、公式以外から取得した画像の利用は一切禁止。
> - 生成したテキストはそのまま公開せず、最初のうちは人間による「生成結果のチェック」フローを設ける。
