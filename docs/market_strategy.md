## 📊 収益化難易度評価

### アダルトアフィリエイト全体の難易度：★★★☆☆（中程度）

あなたの認識は**正しい**。アダルトアフィリエイトは収益化しやすいジャンルの1つ。

| 比較項目 | アダルトアフィリエイト | 一般アフィリエイト |
|---------|---------------------|-----------------|
| **企業参入** | 少ない（広告が出せないため） | 多い（競合激化） |
| **ユーザー購買意欲** | 高い（Need-Basedな欲求） | 低〜中 |
| **単価** | 高い（1,000〜5,000円/成約） | 低〜中 |
| **SNS誘導** | 困難（規約制限多い） | 容易 |
| **グーグルSEO** | 難しいが個人でも戦える | 企業に勝ちにくい |
| **AdSense併用** | 不可 | 可能 |

## 🏆 競合サイト状況（ニューハーフ特化）

### 競合の強さ評価：★★★☆☆（一般より弱い）

**なぜニューハーフ特化は狙い目か：**
- メジャーな「素人」「巨乳」カテゴリより競合が少ない
- 特定ユーザーの熱量が高い（リピート率・購買意欲↑）
- 専門特化サイトが少なく、企業サイトがほぼ参入していない

### 競合サイトのパターン（調査ベース）

| タイプ | 特徴 | 強さ |
|--------|------|------|
| **大手アダルトまとめサイト** | 全ジャンル扱い、SEO強い | ★★★★★ |
| **ニューハーフ特化ブログ** | 個人運営、記事の質にバラつき | ★★★☆☆ |
| **口コミ・レビューサイト** | ユーザー投稿型 | ★★★☆☆ |
| **SNS型（X/note）** | フォロワー依存、即効性あり | ★★☆☆☆ |

**ニューハーフ専門特化サイトは少ない** → ここが狙い目

## 🎯 差別化戦略

### ポジショニング：「ニューハーフAVの専門メディア」

一般アダルトサイトに「ニューハーフコーナー」があるのに対し、
**「ニューハーフだけ」に特化した専門サイト** にすることで差別化。

### 記事タイプ別SEO戦略

#### 1. 作品レビュー記事（量産メイン）
- 狙うキーワード例：`「[女優名] AV おすすめ」` `「[作品タイトル] 感想」`
- Fanza APIで自動取得 → 人間が評価コメントを追加するハイブリッド方式

#### 2. ニューハーフ解説記事（権威性・E-E-AT向け）
- 狙うキーワード例：`「ニューハーフ AV ランキング」` `「ニューハーフ おすすめ 初心者」`
- 検索ボリュームが高く、競合が書きにくい「専門的な視点」で差別化

#### 3. ニッチ特化ランキング記事（コンバージョン高）
- 例：「〇〇好きにおすすめのニューハーフ女優TOP10」
- 「淫乱系 ニューハーフ AV おすすめ」など属性×ニューハーフの掛け算

#### 4. 最新作即日レビュー（鮮度SEO）
- 新着作品を即日〜3日以内にレビュー
- 作品名がキーワードになる（競合ゼロの状態で先行）

## 🛠️ 技術スタック推奨

```
フレームワーク：Next.js（Antigravityで構築可能）
ホスティング：Cloudflare Pages（無料・アダルト比較的寛容）
DB/CMS：Supabase（無料枠あり）or JSONファイル管理
API：Fanza Affiliate API（作品情報自動取得 → 静的ページ生成）
記事生成：Fanza APIデータ + ローカルLLM（Ollama + Llama3）
解析：Google Search Console + Cloudflare Analytics
SEO：Next.js built-in（sitemap.xml, OGP, 構造化データ対応）
```

> ✅ **この構成のメリット：** すべてAntigravityで構築可能・ほぼ無料・SEOも十分対応可

## ⚠️ 重要な落とし穴

1. **Googleインデックスに時間がかかる** → 新サイトは2〜3ヶ月かかることも。焦らず量を積む
2. **記事の質が低いと圏外のまま** → AI生成そのままはNG、人間の手直しが必須
3. **FANZA規約変更リスク** → 定期的に規約確認。突然の報酬レート変更に備えて複数ASP登録
4. **ドメインエイジの重要性** → 可能なら中古ドメイン（アダルト系が使ったもの）が早期に上がりやすい
